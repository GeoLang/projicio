Features

📐 Projections

  • Web Mercator (EPSG:3857)
  • Transverse Mercator / UTM (zones 1–60, north and south)
  • Mercator (ellipsoidal, EPSG:3395)
  • Lambert Conformal Conic (2 standard parallels)
  • Lambert Azimuthal Equal Area (ellipsoidal, EPSG:3035)
  • Albers Equal Area (conic equal-area)
  • Polar Stereographic
  • Cassini-Soldner, Hotine Oblique Mercator, American Polyconic, Equal Earth, Laborde: native projection methods in projicio's own path

🌍 Ellipsoids

  • WGS84 (GPS standard)
  • GRS80 (geodetic reference)
  • Clarke 1866 (NAD27)
  • International 1924
  • Unit sphere

🔄 Transform API

  • High-level EPSG code interface
  • Forward and inverse transforms
  • Thread-safe (Send + Sync)
  • All 120 UTM zones (60 north, 60 south)
  • Native vs PROJ to 1 mm (TM 5 mm at a UTM zone edge)

🖥️ CLI

  • Transform one coordinate pair between any supported CRS
  • An EPSG code or a proj4 projstring on either side
  • projicio info EPSG:27700 names the engine that handles a code
  • --grid NAME=PATH registers a datum shift grid before the transform

🗺️ CRS coverage

  • 5935 EPSG codes resolve, 186 of them on projicio's own math
  • The rest go to proj4rs over an embedded proj4 definition table
  • NTv2 datum shift grids registered at runtime, from a path or from bytes
  • EPSG names, deprecation flags and areas of use from an embedded blob
  • WKT1 and WKT2 read wherever an EPSG code is accepted
  • WebAssembly bindings, grid registration included

Quick Start

use projicio_core::Transform;

// Transform from WGS84 geographic to Web Mercator
let transform = Transform::new("EPSG:4326", "EPSG:3857").unwrap();
let (x, y) = transform.convert(-73.9857, 40.7484).unwrap();
// → (x: -8236050.4, y: 4975301.3) meters
# CLI usage
projicio transform --from EPSG:4326 --to EPSG:3857 -- -73.9857 40.7484
